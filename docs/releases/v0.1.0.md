# v0.1.0

Initial release for Paveda as a portable agent harness.

## Highlights

- SQLite EventStore for lifecycle events, session summaries, router decisions,
  instincts, schema migrations, and time-filtered CLI queries.
- EventStore CLI coverage for project and user store scopes, instinct
  add/list/status updates, session status, event replay, router traces, and
  decision export.
- Claude Code hook adapter and installer for `SessionStart`, `PreToolUse`,
  `PostToolUse`, and `Stop`.
- Built-in harness hooks for session context, cost guard, destructive command
  blocking, dependency blast checks, tooling enforcement, worktree port
  resolution, and test process cleanup.
- Project-owned hook and check runners under `.harness/hooks` and
  `.harness/checks`.
- SKILL.md loader with project, user, and packaged builtin priority.
- Packaged builtin core harness skills: `/do`, `/specify`, `/plan`,
  `/verify`, `/debug`, `/commit`, `/pr`, and `/surgical-edits`.
- Host skill bundle installer for `.harness`, `.claude`, `.codex`, `.pi`, and
  `.hermes` skill roots, including Codex skill discovery metadata and Hermes
  skill directory registration.
- Canonical context modules rendered into each host bundle target.
- Canonical `AGENTS.md` instruction rendering for each host bundle target.
- Host bundle rendering rewrites host paths, adapts model metadata, supports
  custom target roots, and keeps packaged helper scripts runnable after install.
- Host initialization command that combines bundle installation and adoption
  diagnostics, including follow-up verification commands.
- Runtime smoke and adoption report commands for verifying host readiness and
  EventStore write/replay behavior.
- PAL Router metadata for `/do`, including ambiguity gate blocking and escalation
  signals for tool retries, verify failures, ambiguity, and elapsed time.
- Doctor checks for host skill roots, instruction files, context modules,
  rendered paths, host model metadata, Codex metadata, Hermes registration,
  Claude Code hook settings, project extension executables, and structured
  recovery commands for directly repairable failures.
- Package smoke verifies the packaged CLI, host matrix install/readiness,
  runtime write path, project `/do` router metadata repair, overlapping route
  access, project extension guards, rendered host assets, helper scripts, and
  public-surface content rules.
- Performance smoke verifies EventStore append latency, minimal hook dispatch
  overhead, and 10-skill loading cold path against the spec targets.
- CLI commands for status, event replay, router traces, decision export,
  instincts, hook dispatch, hook install, skill management, adoption
  diagnostics, port resolution, and project checks.

## Local Verification

```bash
pnpm build
node dist/cli.js help
```

## Requirements

- Node.js 22 or newer.
- Runtime dependencies are intentionally empty; SQLite uses the Node.js 22 built-in `node:sqlite`.
