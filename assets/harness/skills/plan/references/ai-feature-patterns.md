# AI Feature Suggestion Patterns

Planner Agent가 TASK_DESCRIPTION을 분석하여 AI 활용 가능성을 판단할 때 사용하는 기준.

## 트리거 키워드

아래 키워드가 TASK_DESCRIPTION에 포함되면 AI 기능 제안을 고려한다:

| 키워드 그룹 | 예시 | 제안 방향 |
|-------------|------|-----------|
| 분류/카테고리 | 분류, 태깅, 카테고리, 라벨링 | 자동 분류, 지능형 태깅 |
| 검색/필터링 | 검색, 필터, 찾기, 조회 | 시맨틱 검색, 지능형 필터링 |
| 분석/통계 | 분석, 통계, 리포트, 대시보드 | 이상 탐지, 패턴 분석, 예측 |
| 텍스트 처리 | 요약, 추출, 파싱, 변환 | LLM 기반 요약/추출 |
| 추천/제안 | 추천, 제안, 자동완성 | AI 기반 추천 시스템 |
| 품질/검증 | 검증, 검토, 리뷰, 품질 | AI 기반 품질 점검 |

## 코드베이스 AI 패턴 확인

제안 전 코드베이스에서 AI 관련 타입과 호출 지점을 검색하여 프로젝트의 AI 활용 방식을 파악한다.

## 제안 원칙

1. **선택사항으로 제시**: AI 기능은 항상 "(선택)" 태그와 함께 제안. 사용자가 명시적으로 승인해야 계획에 포함
2. **기존 패턴 활용**: 프로젝트에 이미 있는 AI 패턴(예: LLM 호출, 임베딩)을 우선 활용
3. **복잡도 경고**: AI 기능 추가 시 예상되는 추가 복잡도를 명시
4. **대안 제시**: AI 없이도 가능한 규칙 기반 대안을 함께 제시
